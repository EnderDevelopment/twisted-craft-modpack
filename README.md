# Twisted Craft

Twisted Craft is a Minecraft modpack designed for version 1.20.1 using Forge. It offers a unique twist on the popular Crazy Craft modpack, providing players with an enhanced and personalized gaming experience. This modpack is perfect for those who enjoy custom Minecraft experiences with a blend of new mechanics, items, and challenges.

## Install

1. Download and install Minecraft version 1.20.1.
2. Install the Forge mod loader for Minecraft 1.20.1.
3. Download the Twisted Craft modpack from the GitHub repository or the EnderDevelopment marketplace.
4. Extract the downloaded modpack into your Minecraft mods folder.
5. Launch Minecraft and select the Forge profile.
6. Start playing with the Twisted Craft modpack.

## Use

1. Launch Minecraft and select the Forge profile.
2. Create a new world or load an existing one.
3. Enjoy the unique features and mechanics provided by the Twisted Craft modpack.
